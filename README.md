# College Database - SQL Class Project

This repository contains my SQL learning journey using MySQL Workbench.

## 📚 Database: College_db
A simple college management database created as part of SQL class.

### Table: Students
| Column | Type | Description |
|--------|------|-------------|
| Student_id | INT (PK) | Unique Student ID |
| Name | VARCHAR(100) | Student Name |
| Age | INT | Student Age |
| Course | VARCHAR(50) | Course Enrolled |
| City | VARCHAR(50) | City Name |

### 🔢 Data
- 10 students from Tamil Nadu
- Courses: GenAI, Java, SQL, ML, ETL, Python, Data Science
- Cities: Chennai, Madurai, Kovai, Trichy, Salem

## 📝 Queries Covered
1.  `CREATE DATABASE` & `DROP DATABASE`
2.  `CREATE TABLE`
3.  `INSERT INTO`
4.  `ALTER TABLE ADD COLUMN`
5.  `UPDATE SET WHERE`

## ▶️ How to Run
1. Open MySQL Workbench
2. Open `College_database.sql`
3. Press ⚡ Execute (run line by line or all together)
4. Check Result Grid for output
